# Mobile Applications Collection

A collection of Android applications developed for mobile application development practice.

- **Features**: Draws lines, rectangles, circles, ovals, and custom text.
- **Key Components**: `Exam.java` (Custom View), `MainActivity.java`.

### 6. LayoutManagers (EXPNO6)
This experiment demonstrates Android Layout Managers by using a menu to navigate between different UI structures. It specifically shows how to implement and switch between Linear, Relative, and Table layouts using Intents.
- **Features**: Interactive dashboard to switch between UI styles, demonstration of vertical/horizontal alignment, relative positioning, and grid-based tabular structures.
- **Key Components**: `Intent` (Navigation), `LinearLayout`, `RelativeLayout`, `TableLayout`.

## Getting Started
Each directory is an independent Android Studio project.
1. Open Android Studio.
2. Select **File > Open** and choose the directory of the app you want to explore.
3. Sync Gradle and run the project.
